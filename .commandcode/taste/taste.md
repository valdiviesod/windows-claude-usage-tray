# Taste

## UI / visual consistency
- Wants secondary UI surfaces (tray area, pill, badges) to reuse the app's own typeface and design language — explicitly asked for the app's JetBrains Mono and a look that stays "bien aesthetic" instead of a generic/system widget. Confidence: 0.6
- Prefers status/indicator UI to sit natively inside the Windows shell (taskbar, next to the notification area / keyboard language) rather than as a free-floating window parked in a screen corner — corrected the assistant's corner-docked pill and asked for it in the taskbar. Confidence: 0.55

## Workflow
- After implementing a feature, expects the app to be built and reinstalled/running on their machine ("déjamelo desplegado en el pc"), not just left as source edits. Confidence: 0.55
- Expects new features to be fully documented before considering the work done ("documenta todo"): a dedicated doc under `docs/` plus README/architecture/test-count updates, not just code comments. Confidence: 0.5
